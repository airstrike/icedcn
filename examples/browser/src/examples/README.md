# Examples

Run `cargo run -p browser` and choose **Examples → Receipts** or **Examples → Playground**.

Receipts ports [iced_receipts](https://github.com/airstrike/iced_receipts) to icedcn widgets. It keeps the original screens, layout, messages, calculations, and Action/task flow.

Playground runs a whole Rust program as you type. Its `main` runs in an embedded [rawr](https://github.com/airstrike/rawr) engine, natively and on the web, and the example shows what it printed or the error rustc would give.
