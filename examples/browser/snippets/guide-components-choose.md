## Choose a component

Start with the job the interface needs to perform:

- Forms: [Field](icedcn://component/field), [Input](icedcn://component/input), [Checkbox](icedcn://component/checkbox), [Select](icedcn://component/select), and [Date Picker](icedcn://component/date-picker).
- Actions: [Button](icedcn://component/button), [Button Group](icedcn://component/button-group), [Dropdown Menu](icedcn://component/dropdown-menu), and [Command](icedcn://component/command).
- Structure: [Card](icedcn://component/card), [Tabs](icedcn://component/tabs), [Sidebar](icedcn://component/sidebar), and [Separator](icedcn://component/separator).
- Overlays: [Dialog](icedcn://component/dialog), [Sheet](icedcn://component/sheet), [Popover](icedcn://component/popover), and [Tooltip](icedcn://component/tooltip).
- Feedback: [Alert](icedcn://component/alert), [Progress](icedcn://component/progress), [Spinner](icedcn://component/spinner), and [Toast](icedcn://component/toast).
- Reading and data: [Typography](icedcn://component/typography), [Table](icedcn://component/table), [Code Block](icedcn://component/code-block), and [Conversations](icedcn://guide/conversations).

Use a component's examples and API reference for its builder options and supported interactions. The component list in the sidebar remains the complete browsing index.
