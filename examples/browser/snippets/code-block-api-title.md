### Title

A filename or a label, with an optional icon. It truncates.

| Builder | Type | Default | Description |
| --- | --- | --- | --- |
| `code_block::title(label)` | `impl Into<TitleItem>` | - | A label, or any slot. |
| `.icon(icon)` | `impl Into<Text>` | - | An icon before the label, at 14px. |
