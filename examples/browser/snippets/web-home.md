## Build an interface

icedcn is a library of composable native components built with Rust and iced. Explore live previews, then copy the Rust examples into your application.

- Start with [Installation](icedcn://guide/installation) for the tested toolchain and Cargo dependencies.
- Read [Components](icedcn://guide/components) for composition, styling, and controlled or uncontrolled state.
- Use [Create](https://icedcn.airstrike.fyi/create) to tune a theme in a live dashboard and copy its Rust configuration.
- Browse [Examples](https://icedcn.airstrike.fyi/examples) for complete application screens.

## Documentation formats

Each component and guide has an interactive page and a corresponding Markdown document. For example, [Button](https://icedcn.airstrike.fyi/components/button) has its complete prose and Rust examples at [button.md](https://icedcn.airstrike.fyi/components/button.md). The [documentation index](https://icedcn.airstrike.fyi/llms.txt) links to all exported pages.
