The upstream language list includes bash, CSS, diff, HTML, JavaScript, JSON, JSX, Markdown, Python, SQL, TSX, TypeScript and YAML, with aliases such as `ts`, `js`, `sh` and `yml`.

The native recipes ask iced's installed parser for `ts`, `tsx`, `json`, `css`, `py` and `sh`. Unknown text remains plain. Register or choose a different parser in your application when you need another grammar.
