## API Reference

| Builder | Behavior |
|---|---|
| `status_marker(content)` | Creates an inline status or activity note. |
| `.icon(widget)` | Adds a 16-point icon before the label. |
| `.style(Separator)` | Adds a rule on each side of the note. |
| `.style(Border)` | Draws a rule below the note. |
| `.stacked(true)` | Centers the icon above the label. |
| `shimmer(label)` | Animates a highlight across a visible label. |
