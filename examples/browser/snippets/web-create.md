## Customize a theme

Open [Create](https://icedcn.airstrike.fyi/create) to adjust the theme while viewing real icedcn components in a dashboard. The customizer exposes colors, typography, and corner styling. Try light and dark appearances to inspect the design across both modes.

The Create preview keeps its theme separate from the documentation pages. Changes remain in memory as you move around the browser; they are not a saved account preference.

## Use the result

Open the code view and choose **Copy code** to copy the current Rust configuration into your icedcn application. Follow [Installation](icedcn://guide/installation) to set up the application first, then see [Theming](icedcn://guide/theming) for palettes, semantic color roles, and widget styles.

The preview controls demonstrate interface behavior. They do not connect to banking, billing, or other live services.
