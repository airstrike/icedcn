## Complete interfaces

The Examples gallery shows how icedcn components work together in application screens. Open **Receipts** to explore the current complete example.

### Receipts

[Receipts](https://icedcn.airstrike.fyi/examples/receipts) is a sales notebook adapted from [iced_receipts](https://github.com/airstrike/iced_receipts). It preserves the original application screens, layout, messages, calculations, and action/task flow while using icedcn widgets.

To run the browser from a checkout:

```sh
cargo run -p browser
```

Choose **Examples → Receipts**. Read the [Components guide](icedcn://guide/components) for how to combine controls and keep state in your own application.
