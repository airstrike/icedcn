## Complete interfaces

The Examples gallery shows how icedcn components work together in application screens. Open **Receipts** for a complete application, or **Playground** for a Rust scratchpad.

### Receipts

[Receipts](https://icedcn.airstrike.fyi/examples/receipts) is a sales notebook adapted from [iced_receipts](https://github.com/airstrike/iced_receipts). It preserves the original application screens, layout, messages, calculations, and action/task flow while using icedcn widgets.

### Playground

[Playground](https://icedcn.airstrike.fyi/examples/playground) is a Rust scratchpad. Its program runs on every edit in an embedded [rawr](https://github.com/airstrike/rawr) engine, and Output shows what `main` printed or the error rustc gives.

To run the browser from a checkout:

```sh
cargo run -p browser
```

Choose **Examples → Receipts** or **Examples → Playground**. Read the [Components guide](icedcn://guide/components) for how to combine controls and keep state in your own application.
