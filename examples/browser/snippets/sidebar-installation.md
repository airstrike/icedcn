A sidebar that collapses to icons on desktop and opens in a sheet on narrow screens. Try the team switcher, expand a navigation group, or use the toggle beside the panel.

## Installation

Add the local icedcn checkout to your application.

```sh
cargo add icedcn --path ../icedcn
```

Use the checkout’s iced revision and Cargo patch tables in your workspace manifest. The sidebar toggle includes its own icon.
