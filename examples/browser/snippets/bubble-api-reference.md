## API Reference

| Builder | Behavior |
|---|---|
| `bubble(content)` | Frames a content slot. |
| `.style(variant)` | Primary, Secondary, Muted, Tinted, Outline, Ghost or Destructive. |
| `.align(Horizontal)` | Aligns the bubble in its row. |
| `.reactions(content, edge, side)` | Anchors a reaction to a corner. Include a text alternative when a reaction conveys status. |
| `bubble::group(items)` | Groups adjacent bubbles with eight points of spacing. |
