## API Reference

| Builder | Behavior |
|---|---|
| `code_block(source)` | Displays borrowed or owned output. |
| `CodeBlock::lines(rows)` | Renders each styled slot as one line. |
| `title`, `actions`, `footer` | Set the optional panel slots. |
| `start_line(n)` | Numbers rows starting at `n`. |
| `wrap(bool)` | Wraps long lines when enabled. |
| `compact(bool)` | Reduces padding and base type size. |
| `height(px)` | Scrolls output within a fixed-height viewport. |
| `font`, `style` | Customize the plain text typeface or the panel style. |
