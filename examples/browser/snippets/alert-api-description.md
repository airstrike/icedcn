### AlertDescription

The description of the alert is set with `.description(description)` on the `alert()` builder.

| Builder | Type | Default | Description |
| --- | --- | --- | --- |
| `.description(description)` | `impl IntoFragment` | `None` | Body text at 14px with a 20px line height. Muted by default; destructive at 90% opacity in the destructive variant. |
