## Features

- Set an icon or an image with `.media(...)`.
- Choose from five upload states. `Uploading` and `Processing` shimmer the filename. `Error` highlights the media, border, and description.
- Choose three sizes and a horizontal or vertical layout.
- Open a file or dialog with a card trigger and keep independent buttons for actions such as remove, copy, and retry.
- Group attachments in a horizontally scrollable, snapping row with an edge fade.
- Supply your own media and action widgets to customize their appearance. Use `.style(...)` for the card surface; colors default to the active theme.
