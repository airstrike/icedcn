## A sales notebook

Receipts is a complete example application adapted from [iced_receipts](https://github.com/airstrike/iced_receipts). It uses icedcn widgets while retaining the original screens, layout, messages, calculations, and action/task flow.

Open [the interactive example](https://icedcn.airstrike.fyi/examples/receipts) to explore its sales notebook. Use the surrounding Examples navigation to return to the gallery. This is a demonstration inside the component browser.

## Run locally

From an icedcn checkout:

```sh
cargo run -p browser
```

Choose **Examples → Receipts**. The implementation lives in `examples/browser/src/examples/receipts.rs` and its sibling `receipts/` directory. For setting up your own application, start with [Installation](icedcn://guide/installation); for adapting widget state and messages, read [Components](icedcn://guide/components).
