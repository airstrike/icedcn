### Header

A row above the content for a title and actions.

| Builder | Type | Default | Description |
| --- | --- | --- | --- |
| `code_block::header(title)` | `impl Into<HeaderItem>` | - | A title or any slot. A string is the title. |
| `.actions(actions)` | `impl Into<Actions>` | - | Actions at the end. A single button works too. |
