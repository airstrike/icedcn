# Built with Trace

Every pattern below is a composition of `Trace` parts. See [AI Elements](https://ui.shadcn.com/docs/ai-elements) for examples and code.

| Pattern                                                      | Shows                                                            |
| ------------------------------------------------------------ | ---------------------------------------------------------------- |
| [Chain of Thought](https://ui.shadcn.com/docs/ai-elements/radix/chain-of-thought) | A summary that expands into the steps behind it.                 |
| [Plan](https://ui.shadcn.com/docs/ai-elements/radix/plan)                         | The steps the agent plans to take, and how far it has got.       |
| [Queue](https://ui.shadcn.com/docs/ai-elements/radix/queue)                       | The agent's todo list, split into what is left and what is done. |
| [Reasoning](https://ui.shadcn.com/docs/ai-elements/radix/reasoning)               | The agent's thinking as it streams.                              |
| [Sources](https://ui.shadcn.com/docs/ai-elements/radix/sources)                   | The links the agent used for a reply.                            |
| [Stack Trace](https://ui.shadcn.com/docs/ai-elements/radix/stack-trace)           | A failed tool call and its stack frames.                         |
| [Subagent](https://ui.shadcn.com/docs/ai-elements/radix/subagent)                 | A subagent run, with its tool calls and result.                  |
| [Task](https://ui.shadcn.com/docs/ai-elements/radix/task)                         | The steps the agent takes, as it takes them.                     |
| [Terminal](https://ui.shadcn.com/docs/ai-elements/radix/terminal)                 | A command the agent runs, with its output as it streams.         |
| [Test Results](https://ui.shadcn.com/docs/ai-elements/radix/test-results)         | A test run by the agent, with its suites and failures.           |
| [Tool](https://ui.shadcn.com/docs/ai-elements/radix/tool)                         | A tool call the agent makes, from input to output.               |
