## Start here

icedcn provides themed controls, layout helpers, and interaction patterns for native iced applications. This browser contains runnable examples and the Rust used to compose them.

- [Installation](icedcn://guide/installation) runs the browser and builds a first window.
- [Components](icedcn://guide/components) helps choose a control and explains composition.
- [Conversations](icedcn://guide/conversations) covers keyed transcripts and streamed text.
- [Theming](icedcn://guide/theming) explains palettes, variants, tweaks, and custom designs.
- [Cargo](icedcn://guide/cargo) lists workspace packages, features, and checks.

Use the search field to find a component or a section within its documentation. On desktop, the right-hand contents links jump within the current article. The theme and font controls let you inspect the same example with different rendering choices.
